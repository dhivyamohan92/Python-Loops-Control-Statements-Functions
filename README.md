# Python-Loops-Control-Statements-Functions

📌 Project Overview

This project is a Python programming assignment focused on understanding and implementing loops, control statements, and functions.

The assignment contains three practical programs:

🎯 Number Guessing Game – Uses a while loop and control statements.
✖️ Multiplication Table Generator – Uses a for loop and range().
🧮 BMI Calculator – Uses a user-defined function with parameters.

The programs demonstrate basic logical problem-solving and user interaction in Python.

🎯 Objectives

The main objectives of this assignment are to:

Understand iteration using while and for loops.
Use control statements such as break, continue, and else.
Create and call user-defined functions.
Pass arguments to functions using parameters.
Accept and process user input.
Apply conditional statements to solve problems.
Display results using formatted output.

📚 Tasks
🎯 Task 1: Number Guessing Game
Description

A random number between 1 and 10 is generated using random.randint().

The user gets a maximum of 3 valid attempts to guess the secret number.

The program provides feedback:

If the guess is too low → displays "Too low. Try again."
If the guess is too high → displays "Too high. Try again."
If the guess is outside 1–10 → displays an invalid-range message.
If the guess is correct → congratulates the user.
Python Concepts
while loop
if / elif / else
break
continue
while-else
random.randint()
User input
Example
Guess the number (between 1 and 10): 2
Too low. Try again.

Guess the number (between 1 and 10): 5
Too high. Try again.

Guess the number (between 1 and 10): 3
Congratulations! You guessed the correct number.
